4. Temuan Unik (Hanya Ditemui Oleh Satu Reviewer)

XSS via reflected user input

Qwen

Qwen

N+1 query pattern di DB service
Campaign stats dikira dengan `.reduce()` di JS bukan Prisma aggregation. Boleh ganti dengan `_sum` untuk performance.
Qwen
API versioning strategy
Semua routes di `/api/*` tanpa version prefix. Sebarang breaking change akan break semua clients.
Qwen
Stripe subscription + Monetization plan
Qwen satu-satunya yang cadangkan sistem Stripe, tier enforcement, referral system, dan RAG pipeline secara terperinci dengan code.
Qwen
Encrypt sensitive data at rest
